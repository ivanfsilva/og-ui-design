# 🎨 Fundamentos de UI Design

Este diretório contém os projetos práticos desenvolvidos durante o treinamento de UI Design para Iniciantes da Origamid (Instrutor: André Rafael).

O objetivo destes exercícios foi aplicar conceitos de hierarquia visual, espaçamento, tipografia e alinhamento, simulando interfaces mobile.

Projeto focado em diagramação de imagens e blocos de texto para um aplicativo de turismo.

## 🛠️ Tecnologias e Ferramentas

- **Design e Prototipagem:** Figma _(Modelagem visual do front-end, análogo à UML para o back-end)_
- **Ambiente de Desenvolvimento:** WebStorm _(Gestão do repositório local e edição de código)_
- **Controle de Versão:** Git & GitHub _(Versionamento de artefatos estáticos `.fig` e documentação)_
- **Documentação:** Markdown & HTML5 _(Estudo complementar/iniciativa própria para controle aprimorado de exibição de mídia e formatação)_
- **Arquitetura de Projeto:** Abordagem Full Stack _(Estruturação lógica de diretórios e versionamento inspirados nas melhores práticas de engenharia de software)_
