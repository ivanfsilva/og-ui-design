Este repositório contém os projetos práticos e exercícios desenvolvidos durante o treinamento de **UI Design para
Iniciantes** da **Origamid** (Instrutor: André Rafael).

Na minha jornada para me tornar um desenvolvedor **Full Stack**, entendo que o estudo de UI Design no Figma funciona
como a modelagem fundamental do front-end — da mesma forma que os diagramas de classe da UML servem para projetar a
arquitetura e as regras do back-end em Java.

O objetivo principal destes exercícios é aplicar conceitos cruciais do front-end e da usabilidade — como hierarquia
visual, espaçamento, tipografia, contraste e alinhamento —, construindo pontes sólidas entre a prototipagem de
interfaces e a engenharia de software para aplicações web e mobile.

---

## 🛠️ Tecnologias e Ferramentas

- **Design e Prototipagem:** Figma _(Modelagem visual do front-end, análogo à UML para o back-end)_
- **Ambiente de Desenvolvimento:** WebStorm _(Gestão do repositório local e edição de código/documentação)_
- **Controle de Versão:** Git & GitHub _(Versionamento de arquivos de backup `.fig` e documentação)_
- **Documentação:** Markdown & HTML5 _(Estudo complementar/iniciativa própria para controle aprimorado de exibição de
  mídia e formatação)_
- **Arquitetura de Projeto:** Abordagem Full Stack _(Estruturação lógica de diretórios e versionamento inspirados nas
  melhores práticas de engenharia de software)_

## 🚀 Como Visualizar os Projetos

1. **Protótipos Interativos no Figma:** Clique nos links da coluna **Links** da tabela acima para acessar cada projeto
   diretamente na nuvem (não é necessário ter conta no Figma para visualizar).
2. **Backups Estáticos Offline:** Em cada subpasta do projeto, acesse o
   diretório [`docs/`](./exercicios-praticos/01-projeto-explorando-a-natureza/docs/) para encontrar o arquivo `.fig` com
   a cópia de segurança do projeto original.
3. **Documentação Detalhada:** Cada subpasta possui seu próprio `README.md` detalhando os aprendizados táticos e
   específicos de UI Design daquela tela.
