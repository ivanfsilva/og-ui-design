Este repositorio contiene los proyectos prácticos y ejercicios desarrollados durante el curso de **UI Design para
Principiantes** de **Origamid** (Instructor: André Rafael).

En mi camino para convertirme en desarrollador **Full Stack**, entiendo que el estudio de UI Design en Figma funciona
como el modelado fundamental del front-end, de la misma manera que los diagramas de clases UML sirven para diseñar la
arquitectura y las reglas del back-end en Java.

El objetivo principal de estos ejercicios es aplicar conceptos cruciales de front-end y usabilidad —como jerarquía
visual, espaciado, tipografía, contraste y alineación—, construyendo puentes sólidos entre el prototipado de interfaces
y la ingeniería de software para aplicaciones web y móviles.

---

## 🛠️ Tecnologías y Herramientas

- **Diseño y Prototipado:** Figma _(Modelado visual de front-end, análogo a UML para el back-end)_
- **Entorno de Desarrollo:** WebStorm _(Gestión del repositorio local y edición de código/documentación)_
- **Control de Versiones:** Git & GitHub _(Control de versiones de archivos de respaldo `.fig` y documentación)_
- **Documentación:** Markdown & HTML5 _(Estudio complementario/iniciativa propia para un control mejorado de la
  visualización de medios y formato)_
- **Arquitectura del Proyecto:** Enfoque Full Stack _(Estructuración lógica de directorios y control de versiones
  inspirados en las mejores prácticas de ingeniería de software)_

## 🚀 Cómo Visualizar los Proyectos

1. **Prototipos Interactivos en Figma:** Haz clic en los enlaces de la columna **Enlaces** de la tabla anterior para
   acceder a cada proyecto directamente en la nube (no es necesario tener cuenta en Figma para visualizar).
2. **Respaldos Estáticos Offline:** En cada subcarpeta del proyecto, accede al
   directorio [`docs/`](./exercicios-praticos/01-projeto-explorando-a-natureza/docs/) para encontrar el archivo `.fig`
   con la copia de seguridad del proyecto original.
3. **Documentación Detallada:** Cada subcarpeta posee su propio `README.md` detallando los aprendizajes tácticos y
   específicos de UI Design de esa pantalla.
