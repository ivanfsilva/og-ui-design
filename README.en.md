This repository contains the practical projects and exercises developed during the **UI Design for Beginners** training
course by **Origamid** (Instructor: André Rafael).

On my journey toward becoming a **Full Stack** developer, I view studying UI Design in Figma as essential front-end
modeling — in the same way UML class diagrams serve to architect and design back-end rules in Java.

The main goal of these exercises is to apply crucial front-end and usability concepts — such as visual hierarchy,
spacing, typography, contrast, and alignment —, building solid bridges between interface prototyping and software
engineering for web and mobile applications.

---

## 🛠️ Technologies & Tools

- **Design & Prototyping:** Figma _(Front-end visual modeling, analogous to UML for back-end)_
- **Development Environment:** WebStorm _(Local repository management and code/documentation editing)_
- **Version Control:** Git & GitHub _(Versioning of `.fig` backup files and documentation)_
- **Documentation:** Markdown & HTML5 _(Complementary study/personal initiative for enhanced media display and
  formatting control)_
- **Project Architecture:** Full Stack Approach _(Logical directory structuring and versioning inspired by software
  engineering best practices)_

## 🚀 How to View the Projects

1. **Interactive Figma Prototypes:** Click on the links in the **Links** column of the table above to access each
   project directly in the cloud (no Figma account required).
2. **Offline Static Backups:** In each project subfolder, access
   the [`docs/`](./exercicios-praticos/01-projeto-explorando-a-natureza/docs/) directory to find the `.fig` file
   containing the safety backup of the original project.
3. **Detailed Documentation:** Each subfolder contains its own `README.md` detailing tactical and specific UI Design
   learnings for that screen.
